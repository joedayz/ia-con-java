# Agentic patterns (Spring AI 1.1.6)

Clases portadas de [spring-ai-examples/agentic-patterns](https://github.com/spring-projects/spring-ai-examples/tree/main/agentic-patterns), alineadas con la guía [Building Effective Agents](https://docs.spring.io/spring-ai/reference/api/effective-agents.html).

| Clase | Patrón |
|-------|--------|
| `ChainWorkflow` | Prompt chaining (+ `chainSteps` para orquestación Java) |
| `ParallelizationWorkflow` | Paralelización LLM y `parallelExecute` para agentes |
| `RoutingWorkflow` | Clasificación + ruta especializada |

Usado como dependencia Maven por los steps de `section-2`.
